# Chill Zone Allied Teams — 2.0 alpha4 (Minecraft 26.3)
This is a **source port**, not a ready-to-install JAR. The original Allied code and features have not been intentionally changed.

- Gradle wrapper: 9.8 (Fabric Loom 1.19.3 requires >=9.8)
- GitHub Actions runs with JDK 25.
- To build: commit all files including `gradle/wrapper`, then GitHub Actions > Build.
- The Java code and original MIT license are preserved.
- Do not install this ZIP in your server mods directory.
- Build not verified in the current offline runtime.
